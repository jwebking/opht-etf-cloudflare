# PRD: Ophthalmology Sector ETF — \$OPHT Tracker

**Version:** 1.1

## Overview

A single-page, investor-grade web visualization that tracks a custom-constructed ophthalmology sector index — the **Ophthalmology Sector ETF (\$OPHT)** — against benchmark market indices. The tool is designed to be visually impressive, shareable, and credible, aimed at professionals in or adjacent to the ophthalmology industry who want sector-level market intelligence without being professional investors themselves.

***

## Problem Statement

No publicly traded index or ETF exists that isolates the ophthalmology sector as a standalone investable category.  Industry insiders — ophthalmologists, practice owners, device reps, pharmaceutical professionals — have no single place to see how "their industry" performs as a financial asset class. This tool fills that gap with a polished, real-data visualization that doubles as a calling card for the builder's body of work.[^1]

## Index Construction Methodology

### Universe Definition: Pure-Play Rule

Professional sector ETFs like VanEck's BBH (Biotech) require that companies generate **at least 50% of their revenues from the target sector** to qualify for inclusion. Their newer "ultra-pure play" products (e.g., GPZ) require 75%+. The **recommendation for \$OPHT v1** is the **50% revenue threshold** — a company must derive at least 50% of its revenue from ophthalmology-related products, devices, procedures, or pharmaceuticals. This is the most widely recognized standard in thematic ETF construction and prevents dilution from conglomerate holdings.[^3][^5][^6]

This means:

- ✅ **Include:** ALC (Alcon), GKOS (Glaukos), RXST (RxSight), HROW (Harrow) — pure-play ophthalmology
- ⚠️ **Borderline, document reasoning:** ABBV (AbbVie) — ophthalmology is a major segment but not majority revenue
- ❌ **Exclude:** EL (EssilorLuxottica) — primarily eyewear/retail, not clinical ophthalmology; SYF (Synchrony/CareCredit) — financial services company


### Foreign-Listed Companies \& ADRs

VanEck's approach (followed by most US-listed sector ETFs) is to include **both domestic and US-listed foreign companies** — meaning foreign companies that trade as **ADRs on US exchanges** are eligible, while companies that only trade on foreign exchanges (e.g., Tokyo Stock Exchange, Frankfurt) are excluded. This is called the **"US-listed" universe rule** — it keeps the basket accessible, liquid, and in USD, while still allowing global coverage (BBH, for example, holds companies from China, Ireland, and Germany this way).[^4][^6]

**Recommendation for \$OPHT:** Include any ophthalmology company listed on NYSE, NASDAQ, or as an OTC ADR with meaningful liquidity. Exclude foreign-only listings (e.g., Topcon on Tokyo Stock Exchange) unless a liquid ADR exists.

### Weighting Options

| Mode | Description | Industry Analog |
| :-- | :-- | :-- |
| **Market-Cap Weighted** *(default)* | Float-adjusted market cap as % of total index market cap | SPDR Sector ETFs, VanEck BBH [^6] |
| **Equal Weighted** | Identical weight per holding, recalculated daily | Invesco S\&P Equal Weight ETFs [^7] |
| **Capped (25%)** | Market-cap weighted, but no single holding exceeds 25% of index | VanEck GPZ uses 12% cap; BBH uses 25% [^5][^4] |

### Rebalancing

- **Daily rebalancing** using end-of-day market cap data for v1
- Market caps fetched daily via FMP `/profile` endpoint per ticker


### Return Calculation

- **Dividend-adjusted (total return approximation):** Uses adjusted close prices from FMP, which account for dividends and splits — the same methodology used by Robinhood and Fidelity for historical charts. This is the standard across sector ETF performance reporting.[^8]
- All lines indexed to **100 at the start of the selected time window** for apples-to-apples visual comparison

## Data Architecture

### API Stack

| Provider | Purpose | Free Tier |
| :-- | :-- | :-- |
| **Financial Modeling Prep (FMP)** | Historical adjusted close, market cap, SPY/VTI data | 250 req/day |
| **Finnhub** | Backup/redundancy; real-time quote fallback | 60 calls/min free |

FMP is the primary source for all historical data, adjusted close prices, and market cap figures. SPY and VTI are fetched as standard equity tickers — no special index endpoint needed.[^9][^10][^11]

### Caching Strategy (Critical for Free Tier)

- On first load: fetch full 10Y history per ticker → cache to Vercel KV or a static JSON file
- Daily: incremental append of latest EOD close only (1 call per ticker per day)
- All time range calculations run **client-side** from cached data — the API is never called on page load after initial seeding
- This keeps the app well within the free 250 req/day limit regardless of traffic


### S\&P 500 Benchmark Proxy

| Benchmark | Ticker | Purpose |
| :-- | :-- | :-- |
| S\&P 500 | **SPY** (SPDR S\&P 500 ETF) | Primary benchmark, default ON |
| Total Market | **VTI** (Vanguard Total Stock Market ETF) | Secondary benchmark, default OFF |

SPY is the most recognized benchmark proxy globally and the standard used by professional ETF marketing materials. VTI gives a broader market comparison for users who want it.[^11][^12]

## Features

### Core Chart

- Single interactive line chart using **TradingView Lightweight Charts** — gives the most "Bloomberg/professional terminal" feel of any free charting library
- **Lines:**
    - \$OPHT — Primary, `#D3F060`
    - SPY — Default ON, muted teal
    - VTI — Default OFF, muted blue
- All lines indexed to 100 at window start


### Time Range Control

Top-of-chart segmented pill control (TradingView-style):

`1D · 7D · 1M · 6M · 1Y · 5Y · 10Y`

- Rolling windows ending at latest available trading day
- **1D** uses most recent EOD session (not intraday streaming — v1 constraint, upgradeable in v2)
- Exact calendar offsets (not trading-day approximations)
- **Default on load:** `1Y`


### Weighting Toggle

Three-option segmented control above the chart:

`Market Cap · Equal Weight · Capped (25%)`

- Switching recalculates the \$OPHT line only; benchmark lines unaffected
- **Default on load:** `Market Cap`


### Benchmark Toggle

Two independently toggleable chips: `SPY` and `VTI`

- **Default on load:** `SPY ON`, `VTI OFF`
- Max 3 lines on chart at any time (OPHT + SPY + VTI) — keeps it readable
- The weighting toggle and benchmark toggle operate independently; weighting only affects the \$OPHT line, benchmark chips control their respective lines


### Hover Tooltips

Vertical crosshair with tooltip on hover:

- Date
- \$OPHT value + % return from window start
- SPY % return (if enabled)
- VTI % return (if enabled)


### Summary Stats Bar

Displayed below the chart for the active time window:

```
$OPHT (Market Cap): +24.3%   |   SPY: +12.1%   |   VTI: —
```

Outperform/underperform indicated by subtle opacity or icon — no aggressive red/green, consistent with brand palette.

### Holdings Table

Below the summary stats bar. Lists all index constituents under the active weighting mode:


| Ticker | Company | Weight | Market Cap |
| :-- | :-- | :-- | :-- |
| ALC | Alcon Inc. | 34.2% | \$41.2B |
| GKOS | Glaukos Corp. | 18.7% | \$9.1B |
| ... | ... | ... | ... |

Adds transparency and credibility, mirrors how real ETF providers publish holdings.[^5][^6]

## Mobile Optimization

The page must be fully responsive. Key mobile considerations:

- Chart fills full viewport width with touch-enabled pan/zoom (TradingView Lightweight Charts supports this natively)
- Time range control wraps to horizontal scroll if needed on small screens (no wrapping to two rows)
- Weighting toggle collapses to a dropdown `<select>` on viewports < 480px
- Benchmark chips remain as toggles but stack vertically if needed
- Holdings table becomes horizontally scrollable on mobile (no column hiding — data integrity preserved)
- Summary stats bar stacks vertically on mobile
- Header collapses to compact logo + ticker lockup on small screens
- Tailwind responsive breakpoints: `sm:` (640px), `md:` (768px), `lg:` (1024px)
